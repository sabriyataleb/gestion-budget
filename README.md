# Gestion de budget

Application Java en console qui permet de gérer un budget total réparti en sous-budgets (alimentation, transport, loisirs, etc.).

## Fonctionnalités

- Définir un budget total
- Ajouter et supprimer des sous-budgets (10 maximum)
- Enregistrer des dépenses dans un sous-budget
- Afficher le montant initial et le montant restant de chaque sous-budget
- Contrôle des saisies : montants négatifs, doublons de noms, dépassement du budget total

## Lancer le programme

Compiler puis exécuter :

    javac Main.java
    java Main

## Technologies

- Java
- Programmation orientée objet (classes Budget, SousBudget, Main)
